ADRIAN PERSONAL PORTFOLIO
=========================

Files:
- index.php  -> the main portfolio page
- projects.php -> the detailed projects page
- style.css   -> colors, spacing, layout, and responsive design
- script.js   -> small JavaScript interactions

HOW TO OPEN:
1. Open apache xampp and put all files inside the htdocs folder
2. Open localhost/portfolio on a browser
3. Open VScode to edit/view codes
