ADRIAN PERSONAL PORTFOLIO
=========================

Files:
- index.html  -> the main portfolio page
- projects.html -> the detailed projects page
- style.css   -> colors, spacing, layout, and responsive design
- script.js   -> small JavaScript interactions

HOW TO OPEN:
1. Keep all three files in the same folder.
2. Double-click index.html.
3. Open index.html in a modern browser.
4. Click a project card to open projects.html and read the full project details.

IMPORTANT:
- Bootstrap 5.3.8 is loaded from the official jsDelivr CDN.
- The image URLs are remote Unsplash images, so an internet connection is needed for the photos.
- Replace "your.email@example.com" with your real email address.
- Replace the GitHub and LinkedIn links with your real profiles.
- Edit the project descriptions in index.html to match your actual work.
